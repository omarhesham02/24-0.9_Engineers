Available Endpoints

User

  • GET /user/ - Get all users
  • POST /user/ - Add a new user
  • GET /user/{userId} - Get user by ID
  • GET /user/{userId}/orders - Get orders by user ID
  • POST /user/{userId}/checkout - Add order to user
  • POST /user/{userId}/removeOrder - Remove order from user
  • DELETE /user/{userId}/emptyCart - Empty cart
  • PUT /user/addProductToCart - Add product to cart
  • PUT /user/deleteProductFromCart - Delete product from cart
  • DELETE /user/delete/{userId} - Delete user by ID

Product

  • GET /product/ - Get all products
  • POST /product/ - Add a new product
  • GET /product/{productId} - Get product by ID
  • GET /product/update/{productId} - Update product by ID
  • PUT /product/applyDiscount - Apply discount to products
  • DELETE /product/delete/{productId} - Delete product by ID

Cart

  • GET /cart/ - Get all carts
  • POST /cart/ - Add a new cart
  • GET /cart/{cartId} - Get cart by ID
  • GET /cart/addProduct/{cartId>> - Add product to cart
  • DELETE /cart/delete/{cartId} - Delete cart by ID

Order

  • GET /order/ - Get all orders
  • POST /order/ - Add a new order
  • GET /order/{id} - Get order by ID
  • DELETE /order/delete/{id} - Delete order by ID
